# OpenStreams

## Installation

This project requires 
- [Node.js](https://nodejs.org/) 
- [Git](https://git-scm.com/)

Getting the project
```sh
git clone https://github.com/ImNotStealth/OpenStreams.git
```
Install the dependencies

```sh
cd OpenStreams
npm install
```

Build & run application
```sh
npm start
```
